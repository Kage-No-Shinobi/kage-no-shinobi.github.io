# kage-no-shinobi.github.io

Personal portfolio for John Okutachi, positioned around prompt engineering, AI evaluation, Python development, backend APIs, and data workflows.

## Resume download

The portfolio downloads `resume.docx` from the repository root. To update the resume later, replace `resume.docx` with the new version and commit/push the change. No HTML edit is needed as long as the filename stays the same.
